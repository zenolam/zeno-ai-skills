# OKR 编写技能

## OKR 核心规范

### Objective（目标）
- **定性描述**：描述要达成什么，不是怎么做
- **鼓舞人心**：有挑战性但可实现
- **时间范围**：通常为季度（Q1/Q2/Q3/Q4）
- **数量限制**：每个周期 3-5 个 O
- **格式**：动词 + 对象 + 修饰词

**示例：**
- ✅ 打造行业领先的用户体验
- ✅ 建立可持续增长的营收体系
- ❌ 完成100个功能开发（太具体，是 KR）

### Key Results（关键结果）
- **定量描述**：可衡量的指标
- **可验证**：期末能明确判断是否达成
- **有挑战**：目标值设定在 60-70% 达成率
- **数量限制**：每个 O 对应 3-5 个 KR
- **格式**：指标 + 当前值 + 目标值

**示例：**
- ✅ 用户留存率从 45% 提升至 60%
- ✅ 月活用户从 10万增长至 15万
- ❌ 提升用户体验（不可衡量）

## 模板

使用 `assets/okr-template.md` 作为基础模板。

## 编写流程

1. **明确时间范围**：确认是哪个季度/年度
2. **制定 Objectives**：3-5 个，定性、鼓舞人心
3. **设计 Key Results**：每个 O 对应 3-5 个，可量化
4. **评审优化**：检查对齐关系，验证可达成性
