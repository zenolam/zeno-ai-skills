# 日报编写技能

## 日报核心要素

### 1. 今天做了什么
- 列出完成的主要工作
- 重点关注产出和结果
- 简洁明了，3-5 条

### 2. 明天做什么
- 列出计划完成的任务
- 与 OKR 目标对齐
- 明确优先级

### 3. 当前 OKR 进度
- 关键指标最新值
- 对比目标值
- 进度百分比

## 模板

使用 `assets/daily-report-template.md` 作为基础模板。

## 编写流程

1. **回顾今天**：列出完成的主要工作
2. **规划明天**：明确待办事项
3. **检查 OKR**：更新关键指标进度
4. **标注风险**：如有阻碍或需要支持
