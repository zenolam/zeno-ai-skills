# Gemini Deep Research 提示词模板

## 市场调研类

```
分析 {year} 年 {行业/领域} 的市场趋势、主要玩家、用户痛点和机会点。请提供：
1. 市场规模与增长趋势
2. 主要竞品分析
3. 用户痛点总结
4. 潜在机会点
5. 参考来源列表
```

### 示例

```
分析 2026 年开发者工具市场的趋势、主要玩家、用户痛点和机会点。请提供：
1. 市场规模与增长趋势
2. 主要竞品分析（前 10 名）
3. 开发者痛点总结
4. 潜在产品机会
5. 参考来源列表
```

## 使用建议

### 提示词优化

1. **明确时间范围**：指定年份或日期范围
2. **指定数据源**：如"重点参考 Hacker News / V2EX"
3. **输出格式**：明确要求结构化输出
4. **引用要求**：要求提供来源链接

### 等待策略

- 简单查询：2-5 分钟
- 复杂研究：10-30 分钟
- 设置超时提醒

### 结果验证

1. 检查引用链接是否有效
2. 验证关键数据准确性
3. 交叉验证重要结论
