# 小红书创作服务平台 - 页面结构参考

## 发布页面

**URL**: https://creator.xiaohongshu.com/publish/publish?target=official

### 主要元素

| 元素 | 说明 | 备注 |
|------|------|------|
| 上传视频 | 上传视频内容 | 选项卡 |
| 上传图文 | 上传图文内容 | 选项卡 |
| 写长文 | 写长文内容 | 选项卡 |
| 上传图片按钮 | 触发文件选择 | 需要先点击触发 |
| 标题输入框 | 填写标题 | 最多 20 字 |
| 正文输入框 | 填写正文 | 最多 1000 字 |
| 话题按钮 | 添加官方话题 | 弹出推荐话题列表 |
| 发布按钮 | 发布笔记 | - |

## 笔记管理页面

| 元素 | 说明 |

| 删除 | 删除笔记 |
